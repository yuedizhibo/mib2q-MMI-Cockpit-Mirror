MMI Cockpit Mirror runtime manifest
===================================

Release: B3-OPT v50 standalone Toolbox integration
Vehicle tested: 2020 Audi Q5L
Firmware gate: MHI2Q_CN_AUG22_P1404
Destination: context 76 / displayable 58
Input: renderer-local full MMI texture
Target rate: 30 FPS
Lifetime: until STOP, full MMI reboot, or watchdog fault recovery

Public Green Menu
-----------------

Toolbox/GEM/mqb-mmiCockpitMirror.esd

  START      Persistent 30-FPS MMI cockpit mirror. On first use it installs
             or migrates Cockpit_Mirror.jar and requests a complete reboot.
  STOP       Removes all runtime markers and restores Audi context 74.
  LOG RECORD Saves a self-contained B3 status/log snapshot to the SD card.

Runtime flow
------------

1. start_direct_upload_test.sh validates the exact P1404 firmware and heals
   stale marker/PID files left by a full MMI reboot.
2. ensure_cockpit_mirror_controller.sh verifies Cockpit_Mirror.jar. If a legacy
   carplay_hook.jar exists, it is backed up to the SD card before migration;
   installation is transactional and requests a full reboot.
3. direct_upload_test_worker.sh validates all locked native artifacts.
4. The proven v48-style /bin/sh -c preload host starts libcp_mirror's tiny-RFB
   pacing server. The actual 1024x480 MMI texture is read inside the renderer
   by libdirect_upload immediately before the GLES texture update.
5. After the first real MMI frame and EGL swap, the Java controller activates
   cockpit context 76 with source/displayable 58.
6. direct_upload_restore_watchdog.sh checks recorded worker, renderer, clock
   host, and watchdog PIDs with kill -0. It never parses the truncated P1404
   command line to decide whether a required process is alive.
7. Any failed frame, EGL, Java, heartbeat, or FPS gate disarms the pipeline and
   restores Audi context 74. The mirror never auto-starts after reboot.

RGI boundary
------------

The B3 runtime captures the complete MMI output and does not consume RGI route
messages, start maneuver_render, or require a navigation application. The Java
controller JAR retains modified/derived classes from the public
luka-dev/mib2q-carplay-rgi plugin lineage. See THIRD_PARTY_NOTICES.md at the
repository root; the JAR must not be assumed to be MIT-licensed.
